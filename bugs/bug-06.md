# BUG-06 — Буруу JSON өгөгдөлд амжилттай хариу буцаадаг

**Төлөв:** Илэрсэн  
**Төрөл:** API оролтын баталгаажуулалтын алдаа

## Алдааны тайлбар

`POST /api/books` хүсэлтэд буруу бүтэцтэй JSON өгөгдөл илгээхэд API `200 OK` болон `{"result":"OK"}` хариу буцаасан.

## Алдааг дахин үүсгэх алхам

1. `body.json` файл үүсгэнэ.
2. Файлд дараах дутуу JSON агуулгыг бичнэ:

```json
{"title":
```

3. PowerShell дээр дараах хүсэлтийг ажиллуулна:

```powershell
curl.exe --silent --show-error -i -X POST "http://localhost:3000/api/books" -H "Content-Type: application/json" --data-binary "@body.json"
```

## Хүлээгдэж буй үр дүн

Буруу JSON өгөгдлийг API хүлээн авахгүй бөгөөд `4xx` төрлийн алдааны статус болон тайлбарласан алдааны хариу буцаах ёстой.

## Бодит үр дүн

Дараах хариу буцсан:

```http
HTTP/1.1 200 OK
Content-Type: application/json

{"result":"OK"}
```

## Боломжит нөлөөлөл

Хүсэлт амжилттай болсон мэт харагдавч өгөгдөл буруу эсвэл хадгалагдаагүй байх эрсдэлтэй. Ингэснээр API-ийн хэрэглэгчид хүсэлтийн үр дүнг буруу ойлгож болзошгүй.
