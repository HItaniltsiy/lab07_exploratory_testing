# BUG-08 — API тоон бус оны утгыг хүлээн авдаг

**Төлөв:** Баталгаажуулах шаардлагатай  
**Төрөл:** API оролтын өгөгдөл баталгаажуулалтын алдаа

## Алдааны тайлбар

API-д оны талбарт тоон бус утга илгээхэд хүсэлт амжилттай хариу авч байгаа эсэхийг шалгасан.

## Алдааг дахин үүсгэх алхам

1. Дараах хүсэлтийг илгээнэ:

```powershell
curl.exe -i -X POST "http://localhost:3000/api/books" -H "Content-Type: application/json" --data-raw '{"title":"Туршилтын ном","author":"Туршилтын зохиогч","year":"abc"}'
```

2. HTTP статус болон API-ийн хариуг шалгана.
3. `GET /api/books` хүсэлтээр тухайн бичлэг хадгалагдсан эсэхийг шалгана.

## Хүлээгдэж буй үр дүн

Оны талбар зөвхөн шаардлагад нийцсэн утга хүлээн авах ёстой. Тоон бус утгыг API хориглох ёстой.

## Бодит үр дүн

Өмнөх туршилтын тэмдэглэлд тоон бус оны утгатай хүсэлт амжилттай хариу авсан гэж тэмдэглэсэн. Бичлэг хадгалагдсан эсэх болон бодит хариуг дахин шалгах шаардлагатай.
