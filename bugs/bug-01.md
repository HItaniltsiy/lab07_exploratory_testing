# BUG-01 — Нийт номын тоолуур зөрдөг

**Төлөв:** Илэрсэн
**Төрөл:** Өгөгдлийн нийцтэй байдлын алдаа
**Нөлөөлөл:** Дунд

## Алдааны тайлбар

Номын жагсаалтад 3 ном харагдаж байхад API-ийн `/api/stats` хүсэлт нийт тоог 4 гэж буцаасан.

## Алдааг дахин үүсгэх алхам

1. Програмыг `http://localhost:3000` хаягаар нээнэ.
2. Жагсаалтад харагдаж буй номын тоог шалгана.
3. `curl.exe -i http://localhost:3000/api/stats` командыг ажиллуулна.
4. API-ийн `total` утгыг жагсаалтын тоотой харьцуулна.

## Хүлээгдэж буй үр дүн

API-ийн `total` утга жагсаалтад байгаа нийт номын тоотой тохирч байх ёстой.

## Бодит үр дүн

Жагсаалтад 3 ном байхад API дараах хариуг буцаасан:

`{"total":4,"newest":2020}`
