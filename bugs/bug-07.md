# BUG-07 — API хоосон талбаруудтай өгөгдлийг хүлээн авдаг

**Төлөв:** Баталгаажуулах шаардлагатай  
**Төрөл:** API оролтын баталгаажуулалтын алдаа

## Алдааны тайлбар

`POST /api/books` хүсэлтээр гарчиг, зохиогч, оны талбаруудыг хоосон илгээхэд API хүсэлтийг хүлээн авч байгаа эсэхийг шалгасан.

## Алдааг дахин үүсгэх алхам

1. Програм ажиллаж байгаа эсэхийг шалгана.
2. Дараах хүсэлтийг илгээнэ:

```powershell
curl.exe -i -X POST "http://localhost:3000/api/books" -H "Content-Type: application/json" --data-raw '{"title":"","author":"","year":""}'
```

3. HTTP статус болон хариуг шалгана.
4. Номын жагсаалтад хоосон мэдээлэл нэмэгдсэн эсэхийг шалгана.

## Хүлээгдэж буй үр дүн

Шаардлагатай талбарууд хоосон үед API хүсэлтийг хориглож, алдааны статус болон тайлбар буцаах ёстой.

## Бодит үр дүн

Өмнөх туршилтаар хүсэлт `200 OK` хариу авсан. Гэхдээ хоосон мэдээлэл өгөгдөлд үнэхээр хадгалагдсан эсэхийг дахин шалгах шаардлагатай.
