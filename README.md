# Lab 7 — Exploratory Testing

## 1. Лабораторийн ажлын зорилго

Энэхүү лабораторийн ажлын зорилго нь Exploratory Testing буюу хайгуулын тестийн аргыг ашиглан номын жагсаалтын веб аппликейшний ажиллагааг шалгах, алдаа болон доголдлыг илрүүлэх, тестийн үр дүнг баримтжуулахад оршино.

Туршилтын явцад хэрэглэгчийн интерфейс, хайлтын үйлдэл, өгөгдөл нэмэх, оролтын утгын баталгаажуулалт болон API-ийн хариу үйлдлийг шалгасан.

## 2. Туршилтын хамрах хүрээ

Туршилтыг дараах чиглэлээр гүйцэтгэсэн.

- **Couch Potato Testing:** Оролтын талбаруудад хоосон, буруу, хязгаарын болон давхардсан утга оруулж шалгах.
- **Supermodel Testing:** Хайлтын ажиллагаа, хайлтын үр дүн, текстийн урт, үсгийн том жижиг ялгаа болон жагсаалтын харагдацыг шалгах.
- **API Testing:** Номын жагсаалт авах, ном нэмэх хүсэлт болон буруу өгөгдөлтэй хүсэлтийн хариуг шалгах.
- **Code Inspection:** Эх кодыг шалгаж, илэрсэн асуудлын боломжит шалтгааныг судлах.

## 3. Ашигласан хэрэгсэл

- Node.js
- JavaScript
- Web browser
- Windows PowerShell
- `curl.exe`
- Git болон GitHub

## 4. Туршилтын гүйцэтгэл

Туршилтын явцад дараах асуудлууд ажиглагдсан.

- Хоосон талбар болон буруу утга оруулахад хангалттай баталгаажуулалт хийгдэхгүй байх.
- Он заах талбарт боломжгүй болон бутархай утга оруулахад хүлээгдээгүй үр дүн гарах.
- Давхардсан ном нэмэгдэх боломжтой байх.
- Хайлтын үсгийн том, жижиг ялгаанаас шалтгаалан үр дүн өөрчлөгдөх.
- Нийт номын тоо болон харагдаж буй номын тоо зөрөх.
- API буруу өгөгдөлтэй хүсэлтэд амжилттай мэт хариу өгөх тохиолдол ажиглагдах.

Туршилтын үр дүнг дэлгэрэнгүй тайлан болон screenshot-уудаар баримтжуулсан.

## 5. Тестийн үр дүн

Туршилтын явцад хэрэглэгчийн интерфейс болон API-ийн ажиллагаатай холбоотой хэд хэдэн сэжигтэй доголдол илэрсэн. Зарим тохиолдолд API-ийн бодит хариу болон эх кодоос хүлээгдэж буй ажиллагаа хоорондоо зөрүүтэй байсан тул тухайн орчны ажиллаж буй хувилбар болон эх кодын нийцлийг нэмэлтээр шалгах шаардлагатай.

Илэрсэн асуудлуудын дэлгэрэнгүй тайлбар, тестийн тохиолдлууд болон нотлох screenshot-уудыг `session-report.md` файлаас үзнэ үү.

## 7. Ажиллуулах заавар

1. Repository-г компьютер дээрээ нээнэ.
2. PowerShell эсвэл Terminal ашиглан төслийн хавтас руу орно.
3. Шаардлагатай сангуудыг суулгана.

```bash
npm install
```

4. `package.json` файлд тодорхойлсон тохирох script-ийг ажиллуулна. Жишээлбэл, `start` script байгаа бол:

```bash
npm start
```

5. Терминалд заасан хаягаар веб аппликейшнийг browser дээр нээнэ.

*Тэмдэглэл: Ажиллуулах команд нь төслийн `package.json` файлд тодорхойлсон script-ээс хамаарна.*

## 8. Дүгнэлт

Энэхүү лабораторийн ажлаар Exploratory Testing аргыг ашиглан веб аппликейшний хэрэглэгчийн интерфейс, хайлт, өгөгдөл нэмэх ажиллагаа болон API-ийн хариу үйлдлийг шалгав. Туршилтын явцад илэрсэн асуудлуудыг бүртгэж, нотлох баримтуудыг цуглуулан, эх кодтой харьцуулж судалсан.

Энэхүү ажил нь тестийн тохиолдлыг урьдчилан бүрэн тодорхойлоогүй нөхцөлд системийн боломжит доголдлыг илрүүлэх, тестийн үр дүнг баримтжуулах, цаашдын сайжруулалтын шаардлагыг тодорхойлох дадлага боллоо.
